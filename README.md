# Laboratório de Machine Learning e Visão Computacional

Este repositório serve como um guia técnico para implementação de algoritmos de Machine Learning e Visão Computacional, utilizando TensorFlow, Keras, OpenCV, MediaPipe e Scikit-Learn. 

---

## 🛠️ Tecnologias e Frameworks
* **Deep Learning:** TensorFlow e Keras.
* **Machine Learning:** Scikit-Learn.
* **Visão Computacional & Tracking:** OpenCV e MediaPipe.
* **Manipulação de Dados:** Pandas e NumPy.

---

## 📂 Organização do Repositório
Todos os scripts e códigos de teste estão centralizados na pasta `ScriptsNotebooks/`, cobrindo os seguintes tópicos de estudo:
* Implementações de Redes Neurais Artificiais (ANN) para dados tabulares.
* Estruturação de Redes Neurais Convolucionais (CNN) para classificação de imagens.
* Rotinas de processamento de imagem e detecção de padrões com OpenCV e rastreamento com MediaPipe.
